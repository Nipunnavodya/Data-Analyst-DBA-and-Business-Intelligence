## 📌 Domain Overview
This repository features relational database architecture, complex SQL querying, executive business intelligence dashboards, and exploratory machine learning data pipelines.

---

## 🚀 Projects & Deliverables

### 1. Executive BI Sales Dashboard (Power BI)
* **Tool:** Power BI / Metabase
* **Project Scope:** Designed an interactive executive reporting system tracking critical revenue and retention indicators.
* **Key Implementation:**
  * Formulated advanced DAX measures for YoY growth, churn rates, and average order value.
  * Visualized revenue distribution, regional sales geography, and cohort retention.
  * Added dynamic cross-filtering and drill-down controls for senior decision-makers.

### 2. 3NF Relational Database Schema (MySQL Workbench / DBeaver)
* **Tool:** DBeaver / MySQL Workbench
* **Project Scope:** Architected a normalized relational database schema to ensure relational integrity and high performance.
* **Key Implementation:**
  * Designed comprehensive Entity-Relationship Diagrams (ERD) normalized through Third Normal Form (3NF).
  * Enforced primary/foreign keys, uniqueness rules, and cascading updates/deletes.
  * Wrote optimized SQL scripts using multi-table JOINs, subqueries, CTEs, and window functions.

### 3. Customer Churn Data Analytics (Python)
* **Tool:** Python (Pandas, Jupyter Notebook, Seaborn)
* **Project Scope:** Executed an Exploratory Data Analysis (EDA) project predicting customer attrition trends.
* **Key Implementation:**
  * Cleansed noisy datasets, handled missing values, and engineered behavioral features.
  * Created correlation matrices, boxplots, and distribution curves to uncover churn drivers.
  * Produced actionable, data-backed retention strategies.
